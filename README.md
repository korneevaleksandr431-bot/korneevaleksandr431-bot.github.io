# Университет — демонстрационный сайт

Готовые статические файлы для показа администратору фитнес-клуба. Сайт адаптируется к компьютеру и телефону. Сборка, Node.js и платный сервер для GitHub Pages не требуются.

## Как открыть на компьютере

Откройте `index.html` в браузере. Папка `assets` и остальные файлы должны оставаться рядом. Услуги — `services.html`.

## Публикация на GitHub Pages

1. Распакуйте ZIP. Создайте на GitHub новый репозиторий для демонстрационного сайта. Для простого показа используйте публичный репозиторий.
2. Через **Add file → Upload files** загрузите **содержимое** папки `univerfit-github`: `index.html`, `services.html`, CSS, `app.js`, `.nojekyll`, README и папку `assets`. Не загружайте ZIP вместо файлов. `index.html` должен находиться в корне репозитория, а не во вложенной папке.
3. Сохраните файлы кнопкой **Commit changes**.
4. Откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем **Save**.
5. Дождитесь завершения публикации. GitHub покажет адрес сайта на странице Pages. Откройте его и отправьте администратору именно этот адрес. Он будет работать с её компьютера и телефона, даже когда ваш компьютер выключен.

Официальная инструкция: https://docs.github.com/en/pages/quickstart

Все внутренние ссылки относительные, поэтому сайт можно размещать по адресу репозитория `https://USERNAME.github.io/REPOSITORY/`.

## Что важно для показа

- Это просмотр сайта для администратора, без отдельного кабинета и логина. Владелец публичной ссылки сможет открыть его.
- Форма проверяет данные и подставляет выбранный тариф или тренера, но **не отправляет заявку в клуб**. Это написано прямо в форме. Прямой звонок и маршрут доступны.
- Фотографии карт и трёх тренеров восстановлены из материалов пользователя. У месячного абонемента — фотография шкафчиков, как согласовано.
- Иллюстрация в программе «Здоровая спина» отмечена как иллюстрация, не фотография клуба.
- Для Рамзеса использовано описание достижений из карточки старого сайта: МСМК, дважды вице-чемпион «Мистер Вселенная» (NABBA и NAC). Отличающийся титул из рекламного баннера пока не добавлен.
- Цены, даты акций, расписание, часы и состав программ перед коммерческим запуском нужно подтвердить у клуба. Просроченные акции не скрываются автоматически.
- Для приёма настоящих заявок позже нужно подключить серверную отправку. Секреты Telegram-бота нельзя размещать в HTML или JavaScript публичного репозитория.

## Возврат к прежней версии

Предыдущие варианты локально сохранены в `outputs/univerfit-updated/versions/services-v2` и `services-v3`; эта версия создана отдельно. После публикации историю изменений хранит GitHub.
